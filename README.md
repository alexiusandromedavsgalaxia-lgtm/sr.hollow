# SR HOLLOW

A React + Three.js browser horror game inspired by the house layout and atmosphere of the first GRANNY release.

## Included
- Playable first-person 3D house
- Original procedural geometry
- Dynamic lighting and shadows
- WASD + mouse controls
- Granny chase AI
- Exit objective
- Win / caught states
- Responsive browser UI

Run locally:

```bash
npm install
npm run dev
```

This project uses original code and procedural assets rather than extracted game files.
